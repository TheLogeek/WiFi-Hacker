# WiFi-Hacker
WiFi-Hacker is a dictionary attack program that tests 2300+ commonly used passwords on a WiFi network in an attempt to get the password.


**Cloning**


git clone https://github.com/TheLogeek/WiFi-Hacker.git

**Running the program**

cd WiFi-Hacker

pip install -r requirements.txt

python3 wifihacker.py
